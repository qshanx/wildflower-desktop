# 互动桌面 · 产品需求草案

状态：讨论稿。先定体验和验收，暂不选定开发语言、天气供应商或更新渠道。

## 产品是什么

给想美化电脑、又不希望壁纸拖慢日常使用的人一款可切换主题的互动桌面软件。用户打开软件，选一个主题，预览后点「应用」，回到桌面就能体验。首个主题是池塘花园；以后可以新增画风和玩法不同的主题。Mac 用来先确认视觉与交互，Windows 是首个重点交付平台。

静态图适合只换画面，循环视频适合只看动效。这里用户可以亲手改变场景，几小时后回来看到自己的花长大。关掉设置窗口后，桌面仍按自己的时间和天气变化。

## 软件、桌面和更新

| 场景 | 用户看到的结果 |
|---|---|
| 第一次打开 | 展示主题列表与预览。「应用到桌面」成功才显示已启用；未确认前，现有壁纸保留。 |
| 平时使用 | 关掉主题管理窗口，已应用主题继续运行；主动退出壁纸或选「恢复系统壁纸」时，恢复原桌面。可选「登录后恢复上次主题」。 |
| 切主题 | 先预览再应用。原主题停止绘画并释放素材；存档按主题隔离，切回来继续。桌面图标、选中、拖动、双击、右键和任务栏照常。 |
| 主题更新 | 软件内显示有新版和变化；建议先做手动确认更新，提供自动更新开关。下载完成且校验通过才替换；失败保留旧主题。切换或更新不清除花园。 |
| 软件更新 | 与主题更新独立。建议首版检查并提示用户安装；不在桌面互动中途重启。升级失败能继续用可运行版本，保留主题、存档和设置。 |
| 扩充类型 | 同一个入口预览、应用和停用不同主题。各主题自带资源、设置和玩法；新增主题不要求改写花园，也不常驻加载其他主题。先交付内置主题，第三方可执行插件不在首版范围。 |

## 主题 01 · 池塘花园

依据：[小红书原片](https://xhslink.cn/o/2Iz6cf26aZO)。原片字幕中的单株生长约 5 小时；快进是演示。一天的光色与单株生长用两套时间，不能把环境花海算成亲手种出的花。

| 体验 | 目标与验收 | 当前状态 |
|---|---|---|
| 选种和生长 | 桌面右下角常驻木编种子篮。Mac 普通左键开篮和选种，篮子收起后在草地左键点按或拖撒；点「完成」退出种植，水里不能种。剪刀、插瓶与捕捉沿用 Option + 左键。不同种子长出可辨认的花。从嫩芽、花苞到开花有渐进变化；睡眠和重开后按实际经过时间继续。复刻目标 13 种，先用 3 种验证。建议默认按原片约 5 小时；如果想要种一整天后开花，再单独定成长时长。快进用来验收。 | Mac 左键版有 3 种、约 5 小时及约 6 秒试玩，按阶段切换；左键开篮、选种、播种和退出已通过隔离桥接测试，完整真桌面鼠标路径待复验。还没达到 13 种或自然的连续长大。 |
| 日内场景 | 正式模式跟电脑本地时区，清晨到傍晚的光色平滑过渡，傍晚水面有暖倒影，夜间有月光波纹与星点倒影，浅水和岸石仍有层次。环境草地自动生出花海的效果可以保留，和用户种花的存档分开。夜景不能只给整张图盖深蓝色。 | Mac 昼夜方向已试过。油画质感版已在 Mac 隔离窗口渲染晨、午、暮、夜；画风仍待阿磊验收。 |
| 剪花插瓶 | 选剪刀，点开放的花，再点花瓶。剪下时花离开地面，未开花不能剪；退出重开后已剪和已插状态都正确。原片没确认具体手势，以上是当前方案。 | 已做。在 Mac WebKit 隔离测试中验证剪花、插瓶和重启恢复；Windows 桌面未验。 |
| 萤火虫 | 夜里点飞动的萤火虫捕捉，再点草地放下发光的瓶子，水里不能放。Mac 桌面按 Option + 左键；剪刀模式优先剪花，选任意种子后可捕捉。专用瓶与插花瓶区分，最多放四只；点旧瓶可收起。位置跨夜保留，白天不发光，也不能捕捉。 | Mac 已实现。隔离测试验证捕捉、放瓶、水域拒绝、白天禁捕与重开恢复。静态档及系统减少动态效果时，亮点不飞动。真桌面已实测开篮、选雏菊；草地播种与抓放瓶的实际鼠标路径待复验。 |
| 真实天气 | 用户可手选城市，允许联网后读取该城市的真实天气。下雨时有雨线、水面涟漪和对应光色；雨停后自然恢复。不提供天气时用本地钟照常运行。断网不伪装成实时；短时可沿用仍有效的缓存，过期回到默认天气。 | 未接真实天气。测试场景只能验证雨效；还须用实际服务响应核对城市、更新时间及雨晴切换。 |
| 无干扰 | 常驻画面不放大标题或视频字幕。桌面工具融入岸边，设置从软件入口打开。被窗口覆盖时停止持续绘画，露出后更新到正确的时间状态。 | Mac 油画预览包已移除大标题；此前安装的版本可能仍显示。Windows 鼠标、遮挡停刷未验。 |

## 画质与低占用怎么取舍

先用同一段岸边把素材和光影做对。静态底图负责草、水、石和近岸纹理；共享贴图提供不同朝向的花、茎和叶；短动画负责芽长高、花瓣展开及水面波纹。用前景草叶遮挡一部分花茎，给花簇加贴地阴影。白天、落日、夜晚分别控制草地和水面，月光只在水里随波动。优先用同一画面在相同日夜时段和原片并排评审，不用加花量代替真实感。

| 候选路线 | 适用条件和代价 |
|---|---|
| 单 Canvas 2D + 现有宿主 | 建议拿来先做同素材 Mac 和 Windows 小样。复用现有操作，优先验证贴图和光影；必须把浏览器宿主进程也算进占用。 |
| WebGL 2D | Canvas 达到素材质量后，若性能记录显示瓶颈在大量贴图合成或局部水面光效，再用同素材试。要对比显存、设备兼容与维护成本。 |
| Windows 原生 2D（如 Direct2D） | 如果 Windows 宿主开销持续超预算，或桌面鼠标无法做到与系统操作共存，再评估薄原生宿主。原生可以改变资源和桌面接入成本，不会让同样的花素材自动变真实。具体语言待真机对照后决定。 |

运行中只加载当前主题，贴图合并复用，限制动态画布像素数，尽量让花海近处有动势、远处少更新。静态模式停掉持续动画；遮挡后的真实停刷必须拿渲染帧计数或跟踪证明，不能只看画面被挡住。

## 验收和顺序

1. **Mac 视觉小样**：同一岸段对照验草地、发芽、花苞、盛开、夕阳倒影和夜色。先确认纹理、前后遮挡和动态自然，再铺完整场景。
2. **主题玩法**：走通选种、种植、长大、剪花插瓶、捉萤火虫、真实天气，再验睡眠、重开和离线；全部通过才算花园主题可交付。
3. **Windows 真桌面**：选主题应用，回桌面完整种一次；验证普通图标拖动、双击和右键都能用。用活动动效验证无遮挡持续更新、覆盖后停刷、移开后恢复。验证切主题、升级保留存档和恢复系统壁纸。
4. **同机性能对照**：同一 Windows 电脑、同样花量和档位，对比 1920×1080 和 3840×2160 的空宿主、盛开桌面和遮挡三种状态。记录整组相关进程的私有工作集，另记 GPU 内存、CPU 和采样区间，避免把下载包大小、单块画布估算或虚拟机 RAM 当软件占用。首轮真机数据出来后定内存预算，再决定是否换渲染路线。
